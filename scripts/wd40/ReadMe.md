# wd40
A very little script that recursively searchs directories for cargo projects and cleans them.
I made it because I've had quite a bit of space being taken up by rust projects scattered on my computer.

## Usage
`wd40 [OPTIONS] [DIRECTORY]`
Options:
  -h, --help
    Print this page
  -y, --yes
    Skips warning prompt

Example: `wd40 ~/Documents/Rust`

## Installation
For this script it's not meant to be installed so you can just use curl.
`curl -O https://raw.githubusercontent.com/Olie519/bashed/refs/heads/main/scripts/wd40/wd40`
